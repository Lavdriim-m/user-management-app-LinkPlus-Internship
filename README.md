# User Management App (React)

Internship challenge app demonstrating:
- Data fetching from JSONPlaceholder
- Users list (table)
- Client-side search (name/email)
- User details page (routing)
- Add user form (local only) with validation
- Sorting (bonus)

## Tech
- React (Vite)
- React Router

## Run locally
```bash
npm install
npm run dev
```

## Notes
- Added users are local only (not persisted to API).
- Details page uses JSONPlaceholder data.
